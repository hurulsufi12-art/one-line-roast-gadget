# One-Line Roast: The Gadget You Use Every Day

One line (109 characters): a roast of the wireless earbuds used every day.

> My wireless earbuds cut out every time I sneeze, like my own nose filed a restraining order against my music.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
